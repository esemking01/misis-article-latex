# Поиск нечётких дубликатов клиентов: эксперименты

Код к статье «Петров и Петрова — один человек?».

| Файл | Что делает |
| --- | --- |
| `names.py` | справочники фамилий, имён и отчеств |
| `generate.py` | генерирует тестовую базу `clients.csv` с дубликатами, опечатками и родственниками |
| `matcher.py` | схожесть строк (как `fuzz.ratio` / `token_sort_ratio`), нормализация, пол, даты |
| `experiment.py` | считает точность, полноту и F1 для всех вариантов и порогов, пишет `results.json` |
| `timing.py` | замеряет время полного перебора и перебора с блокировкой |
| `plots.py` | рисует графики по `results.json` |

Запуск:

```
pip install pandas numpy matplotlib
python generate.py
python experiment.py
python timing.py
python plots.py
```

Генератор использует фиксированный seed (2026), поэтому цифры воспроизводятся.
Время в `timing.py` зависит от компьютера.
